# 프로젝트 소개
점성술과 별자리를 통해 일상에 재미와 통찰을 더하는 것을 목표로 합니다. 사용자는 오늘의 운세와 별자리 정보를 확인하고, 궁합과 덕담을 통해 사람들과 소통하며 자신만의 특별한 경험을 만들어갈 수 있습니다.

# 프로젝트 목표
1. Supabase를 활용하여 별자리 정보를 안정적이고 효율적으로 관리
2. 사용자의 생년월일을 기반으로 별자리 및 운세 데이터를 동적으로 매칭
3. 별자리 궁합 계산, 덕담 작성 및 공유 기능을 제공하여 사용자 참여를 증대
4.  Next.js와 Supabase, Zustand 등의 기술을 활용하여 효율적이고 유지보수 가능한 구조 구현

# 기능 구현
### 1. 로그인 페이지
#### **기능 및 주요 구현 내용**
- **사용자 입력 및 유효성 검사**
  - 사용자가 입력한 이메일과 비밀번호를 실시간으로 검증.
  - 메일 형식 확인(유효한 이메일인지 검사) 및 비밀번호 최소 길이(8자 이상) 조건을 확인.
  - 유효성 검사를 통과하지 못하면 입력 필드 아래에 에러 메시지를 표시하여 사용자에게 안내.
- **로그인 처리**
  - 사용자가 입력한 정보를 기반으로 Supabase 인증 API를 호출하여 검증.
  - 로그인 성공: 사용자 세션 정보를 받아와 Zustand 상태 관리에 저장하고 사용자의 세션 상태를 기반으로 개인화된 홈 화면으로 리디렉션.
  - 로그인 실패: 팝업을 통해 사용자에게 오류 메시지를 명확히 전달하고 회원가입 유도 및 리디렉션
- **회원가입 유도 및 리디렉션**
-   계정이 없는 사용자들을 위해 회원가입 페이지로 이동하는 링크 제공.
-   로그인 성공 시 **홈페이지(/)**로 자동 리디렉션되며, 사용자는 자신의 별자리와 운세를 확인할 수 있는 개인화된 화면으로 이동.
### 2. 회원가입 페이지
#### **기능 및 주요 구현 내용**
- **입력 폼 및 유효성 검사**
  - 이메일: 유효한 이메일 형식인지 검증.
  - 닉네임: 필수 입력값이며 최대 10자 제한.
  - 비밀번호 및 비밀번호 확인: 비밀번호는 최소 8자 이상, 비밀번호 확인 필드와 일치 여부 검사.
  - 생년월일 선택: 생년월일을 선택하지 않으면 오류 메시지 표시.
  - 실시간 유효성 검사: 각 입력 필드별로 사용자에게 명확한 오류 메시지 제공.
- **생년월일 선택 UI**
  -  ReactDayPicker 컴포넌트를 사용하여 직관적인 생년월일 선택 기능 제공.
  - 사용자가 생년월일을 선택한 뒤 완료 버튼 클릭 시, 데이터가 입력 폼에 저장.
  - "뒤로 가기" 버튼으로 생년월일 선택 취소 및 초기화 가능.
- **회원가입 처리**
  - 사용자가 입력한 정보를 검증 후 upabase의 인증 API를 통해 회원가입 요청 전송.
  - 회원가입 성공 시: 성공 알림 표시 후 다음 화면으로 리디렉션.
- **회원가입 완료 후 이동**
  - 로그인 페이지로 이동 링크 제공: 이미 계정이 있는 사용자를 위해 안내 메시지와 링크 추가.
###  3. 홈 페이지
#### **기능 및 주요 구현 내용**
- **로그인 상태 확인**
  - 로그인 여부에 따라 사용자 맞춤 화면을 제공합니다.
  - ClientHomePage 컴포넌트에서 로그인 상태를 확인:
    - 로그인 상태: UserHomePage로 이동.
    - 비로그인 상태: GuestHomePage로 이동.
- **데이터 연동**
  - Supabase를 통해 사용자 세션 및 daily_fortunes 데이터를 조회.
  - 로그인한 사용자의 생년월일을 기반으로 별자리 데이터를 매칭.
  - 매칭된 별자리 ID를 활용하여 해당 별자리의 오늘의 운세를 표시.
- **비로그인 사용자**
  - 간단한 별자리 설명 제공.
  - 별자리 소개, 운세, 덕담 등 주요 페이지로 이동 가능한 링크 제공.

### 4. 별자리 소개 페이지
#### **기능 및 주요 구현 내용**
- Supabase의 stellas 테이블에서 데이터를 불러옵니다.
- 각 별자리는 다음 정보를 포함합니다:
- 별자리 이름, 별자리 설명, 배경 이미지, 뱃지 이미지
#### **별자리 정보 표시**
- 기본 상태: 사용자가 별자리를 선택하지 않은 경우, 기본 안내 메시지 표시.
- 별자리 선택: 사용자가 특정 별자리 뱃지를 클릭하면, 선택한 별자리의 정보가 카드 섹션에 동적으로 표시됩니다.
 - 선택된 별자리의 이름, 설명, 배경 이미지가 카드 형태로 보여짐.
### 5. 운세 페이지
#### **기능 및 주요 구현 내용**
1. **운세 조회 인터페이스**
   - 사용자가 생년월일을 선택하여 해당 별자리의 운세를 확인할 수 있는 UI 제공.
   - 날짜 선택 기능
     - ReactDayPicker 컴포넌트를 사용하여 날짜를 선택.
     - 사용자가 생년월일을 입력하면 해당 날짜 기반으로 별자리 ID를 계산하여 운세 페이지로 이동.
2. **운세 유형 선택**
   - **신년 운세**
     - 사용자가 선택한 별자리의 신년 운세 내용을 표시.
     - Supabase에서 new_year_fortunes 테이블의 데이터를 조회하여 별자리 ID에 해당하는 운세를 가져옴.
   - **일일 운세**:
     - 선택한 별자리의 당일 운세를 표시.
     - Supabase에서 daily_fortunes 테이블의 데이터를 조회하여 해당 별자리 ID의 오늘 운세를 가져옴.
3. **운세 결과 저장**
   - 사용자가 운세를 확인한 후, 해당 운세를 저장할 수 있는 기능 제공.
   - **저장 기능**:
     - 선택한 운세(신년 운세 또는 일일 운세)를 서버에 저장.
     - 저장 성공 시, 별도의 공유 페이지(`/share-result`)로 리디렉션.
4. **운세 결과 페이지 구성**
   - **운세 카드**:
     - 운세 결과는 별자리 이름, 운세 내용, 별자리 이미지를 포함하여 카드 형태로 표시.
   - **운세 전환 버튼**:
     - 사용자가 "신년 운세"와 "일일 운세" 간에 전환 가능.
     - 버튼 클릭 시, 현재 선택된 운세 유형에 따라 운세 내용을 업데이트.
### 6. 궁합 페이지
#### **기능 및 주요 구현 내용**
1. **별자리 선택**
   - **사용자 별자리 선택**:
     - stellas 테이블에서 데이터를 불러와 사용자가 자신의 별자리를 선택할 수 있도록 UI 제공.
     - 선택한 별자리를 기반으로 다음 단계로 진행.
   - **상대방 별자리 선택**:
     - 자신의 별자리를 선택한 후 궁합을 알고 싶은 상대방의 별자리를 선택하도록 안내.
   - **선택 확인 및 경고 메시지**:
     - 선택 시 확인 메시지와 사용자 입력 확인 가능.
     - 선택이 확정되면 데이터가 상태에 저장되고, 두 별자리 이름을 URL의 쿼리 파라미터로 전달.
2. **궁합 결과**
   - 두 개의 별자리 선택 완료 시 ChemiResult 페이지로 이동.
   - URL 쿼리 파라미터를 사용하여 두 별자리의 정보를 받아옴.
   - **궁합 데이터 조회**:
     - STELLA_INFO_DATA를 기반으로 선택된 두 별자리의 궁합 점수와 상세 설명을 표시.
   - **결과 UI**:
     - 궁합 점수와 설명을 직관적으로 제공.
     - 선택한 두 별자리 이름과 결과 데이터를 사용자에게 명확히 보여줌.
3. **데이터 로드 및 상태 관리**
   - React Query를 사용하여 stellas 데이터를 비동기로 불러옴.
   - 상태 관리는 React의 useState로 구현하여 사용자의 선택 데이터를 관리.

### 7. 덕담 페이지
#### **기능 및 주요 구현 내용**
1. **덕담 작성 및 저장**
   - 덕담 작성 폼 제공:
     - 사용자가 입력창에 새해 덕담을 작성할 수 있습니다.
      - 로그인하지 않은 사용자는 덕담 저장 버튼이 비활성화되며, 클릭 시 안내 메시지 표시.
       - 로그인한 사용자는 덕담 작성 후 저장 가능.
   - **덕담 저장 처리**:
     - useAddCommentMutation 훅을 사용하여 덕담 데이터를 Supabase에 저장.
     - 작성 후 입력창 초기화.
2. **덕담 목록 조회 및 관리**
   - **목록 조회**
     - Supabase에서 저장된 덕담 데이터를 조회하여 리스트 형태로 표시.
     - 작성자 정보(닉네임, 프로필 이미지)와 작성 시간 함께 표시.
   - **덕담 수정**:
     - 작성자는 본인이 작성한 덕담을 수정 가능.
     - 수정 버튼 클릭 시, 텍스트 필드가 활성화되어 덕담 내용을 편집 가능.
     - 저장 버튼 클릭 시 변경 사항을 Supabase에 업데이트.
   - **덕담 삭제**
     - 작성자는 본인이 작성한 덕담을 삭제 가능.
     - 삭제 버튼 클릭 시 Supabase에서 해당 덕담을 제거.
3. **덕담 목록 UI**
   - **덕담 카드**:
     - 덕담은 카드 형태로 표시되며, 각 덕담은 다음 요소를 포함:
       - 작성자 닉네임, 프로필 이미지, 작성 시간, 덕담 내용.
   - **스크롤 버튼**:
     - 페이지가 길어질 경우, 화면 상단으로 이동할 수 있는 "맨 위로 이동" 버튼 제공.
     - 버튼은 스크롤 위치가 일정 이상 내려가면 활성화.
     - **구현**:
       - GoMoveToTopButton 컴포넌트를 사용하여 부드러운 스크롤 애니메이션 구현.
### 8. 결과 페이지
#### **기능 및 구현 내용**
1. **결과 공유 기능**
   - 사용자가 저장한 일일 운세와 신년 운세 결과를 카드 형태로 표시.
   - 각 결과 카드는 닉네임, 프로필 이미지: 사용자 프로필, 운세 내용, 작성 시간정보를 포함
2. **탭 전환 UI**
   - 일일 운세와 신년 운세를 선택적으로 확인 가능:
     - useState를 활용한 상태 관리
     - 각 탭 클릭 시 조건부 렌더링으로 관련 데이터를 표시.
   - DailyResultList와 YearResultList 컴포넌트를 사용하여 데이터를 렌더링.
3. **Scroll-to-Top 버튼**
   - 스크롤 위치가 300px 이상일 때 버튼이 나타나며, 클릭 시 페이지 상단으로 이동.
   - 사용자 경험을 높이기 위한 편의 기능 제공.
### 9. 마이 페이지
#### **기능 및 구현 내용**
1. **프로필 관리**
   - 사용자는 자신의 프로필 이미지를 업데이트하거나 기본 이미지를 유지할 수 있습니다.
   - 닉네임 변경 기능 제공: 입력된 닉네임은 실시간으로 반영, "변경하기" 버튼 클릭 시 새로운 닉네임 저장.
   - 업로드된 프로필 이미지는 미리보기로 제공되어 사용자 경험 향상.
2. **운세 기록 조회**
   - 사용자가 저장한 일일 운세와 신년 운세를 조회 가능.
   - 운세는 카드 형태로 표시되며 다음과 같은 정보를 포함: 운세 내용, 운세가 저장된 날짜 및 시간, 사용자의 프로필 이미지와 닉네임
3. **댓글 내역 관리**
   - 사용자가 작성한 댓글을 필터링하여 마이 페이지에서만 표시.
   - 댓글 수정 및 삭제 기능 제공: 수정 모드로 전환되어 입력된 텍스트를 업데이트 가능, 삭제 확인 팝업 후 댓글 삭제 처리.
   - 댓글 작성 시간과 작성자를 표시하여 사용자에게 직관적인 인터페이스 제공.
